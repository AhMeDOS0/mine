# Ahmed Command Center

Static personal dashboard for finals, subjects, grades, CGPA planning, cyber security, programming practice, projects, and a live CV log.

## Run

Open `index.html` in the browser. No build step is required.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, `ds-guide.html`, and `README.md`.
3. In the repo settings, open Pages.
4. Choose Deploy from branch, then `main` and `/root`.
5. Open the published URL.

## Data

Progress is saved in browser `localStorage`. Use the export button in the header or CV page to download a JSON backup.

## Features

- Light/dark mode.
- Sun/moon theme switch.
- EN / AR interface switch.
- Study-first top navigation with personal tools grouped in one page.
- Rich subject center for Advanced Programming, Digital Logic Circuits, TOC, Multimedia, Data Structures, System Programming, and Life Skills.
- Per-subject grade components: add, edit, or delete earned/total scores.
- Subject JSON import so new subjects can be added with the same structure and style.
- Full language hub for C++, Java, HTML, CSS, and JavaScript.
- Language JSON import so new languages can be added with the same structure and style.
- Daily coding challenges and automatic CV achievement logging.
- CGPA uses three-decimal precision.
